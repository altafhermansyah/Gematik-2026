# 🌍 KarsaLoka

Platform navigasi isu global (SDGs) dan pemetaan jalur keahlian berbasis AI untuk kompetisi **GEMATIK VI 2026**[cite: 1, 3].

---

## 🚀 Cara Menjalankan

1. **Install dependensi:**
   ```bash
   npm install

```

2. **Setup environment (`.env`):**
Buat file `.env` di root folder:
```env
DATABASE_URL="postgresql://karsa:karsapassword@localhost:5432/karsaloka?schema=public"

```


3. **Sinkronisasi database:**
```bash
npx prisma db push

```


4. **Jalankan aplikasi:**
```bash
npm run dev

```


Buka di browser: `http://localhost:3000`
